# DESIGN — 건의 접수 폼 (report_form_v3.html)

> 대상: `report_form_v3.html` · `css/report-v3.css` · `js/report-v3.js` · `js/muni-sheet.js` · `js/muni-lines.js`
> 구버전 폼(`report_form.html`)은 다루지 않는다.
> 값은 `css/report-v3.css`의 CSS 변수에서 추출했다. 값을 바꾸면 이 문서도 함께 고친다.

## 1. 개요·원칙

| 항목 | 내용 |
|---|---|
| 목적 | 에이전트 오류·불편·개선 의견을 **1화면 1문항**으로 접수 |
| 사용자 | 에이전트를 사용한 KT m&s 직원 |
| 스택 | 순수 HTML + CSS 변수 + ES 모듈. 답은 n8n 웹훅으로 전송 |

**원칙**
1. **주인공은 뮤니** — 나머지는 조용하게. 카드·그림자 없이 큰 질문 한 줄과 입력만 둔다.
2. **한 번에 하나** — 한 화면에 질문 하나. 진행 상황은 상단 막대로 보여준다.
3. **부담 줄이기** — 선택지는 큰 터치 영역(최소 60px), 답하면 자동으로 다음으로 넘어간다.
4. **친근하되 장난스럽지 않게** — 뮤니는 반응하되 입력을 방해하지 않는다.

## 6. 인터랙션·모션

| 동작 | 설명 |
|---|---|
| 단계 전환 | 새 질문이 옆에서 `20px` 슬라이드하며 나타남 (.28s) |
| 선택지 선택 | 선택 후 약 0.38초 뒤 자동으로 다음 단계 |
| **뮤니 시선** | 커서·입력창 방향의 프레임을 고름. 따라잡는 시간 100ms, 몸 쏠림 0.075(너비 대비), 기울기 2.2°, 몸 따라가기 260ms |
| 뮤니 숨쉬기 | 4.4초 주기로 세로 1.4% 늘었다 줄어듦 (`scale` 개별 속성 — JS의 translate/rotate와 충돌 없음) |
| **뮤니 클릭/Enter/Space** | 말풍선 한 문장이 랜덤으로 나옴 (6문장, 한 바퀴 다 보여준 뒤 다시 섞음, 직전 문장 반복 없음) |
| 답 입력 | 입력할 때마다 반짝임(`spark`)과 조명 펄스 |
| 접수 완료 | 폭죽(`confetti`) + 완료 화면 |
| 모션 줄이기 | `prefers-reduced-motion: reduce`이면 숨쉬기·전환 애니메이션 중지 |

말풍선 문장은 `js/muni-lines.js`의 `MUNI_LINES`만 고치면 된다 (한 문장, 40자 안팎).

## 7. 접근성

- 포커스 링: `:focus-visible { outline: 3px solid rgba(85,138,235,.5) }`
- 진행 목록 `aria-label="질문 진행 상황"`, 숫자 `aria-live="polite"`
- 뮤니: `role="button"`, `tabindex="0"`, Enter/Space로 동작, 말풍선은 `role="status"`
- 오류 메시지는 입력과 연결(`aria-invalid="true"`)
- JavaScript가 꺼져 있으면 안내 문구 표시 (`<noscript>`)
- 대비: `--ink`(#1d2340) on `--mist`(#f6f6ff) 높음. `--slate`는 보조 정보에만 사용

## 8. Do / Don't

| Do | Don't |
|---|---|
| 버튼·진행 완료 막대는 `--blue` `#558aeb` | 버튼마다 다른 파랑 사용 |
| 폼 배경은 `--mist` `#f6f6ff` | 흰 배경 + 카드 + 그림자로 무겁게 만들기 |
| 이전/다음 버튼은 같은 크기(132×52) | 이전 버튼만 작게 하거나 텍스트 링크로 두기 |
| 모든 글자 Inter (한글만 대체 폰트) | 질문에만 다른 폰트 지정 |
| 뒤로가기는 아이콘 (로고 높이의 80%) | "대화로 돌아가기" 같은 긴 글자 버튼 |
| 한 화면에 질문 하나 | 여러 문항을 한 페이지에 노출 |
| 뮤니 애니메이션은 `scale`/`translate`/`rotate` 개별 속성으로 분리 | 한 `transform`에 합쳐 충돌시키기 |
