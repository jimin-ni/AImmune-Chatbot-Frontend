# DESIGN — 관리자 대시보드 (dashboard.html · history.html)

> 대상: `dashboard.html`(진행 대기 목록 · 지침서 개정 승인) · `history.html`(민원 처리 내역) · `js/dashboard.js` · `js/history.js`
> 두 화면은 같은 틀(레일·헤더·프로필)을 공유한다. 값은 코드에서 추출했다.

## 1. 개요·원칙

| 항목 | 내용 |
|---|---|
| 목적 | 에이전트 상담 지침 **개정안을 관리자가 승인/반려**하고, 처리 내역을 확인 |
| 사용자 | 지침을 승인하는 관리자 (PC 대형 화면) |
| 스택 | Tailwind CDN + 바닐라 JS, n8n 웹훅 조회·처리 |

**원칙**
1. **위험도가 먼저 보인다** — 붉은색이 가장 위험, 이어서 주황·노랑·파랑. 목록은 위험도 순으로 정렬.
2. **목록 → 상세** — 카드를 누르면 오른쪽에 상세가 열리고, 판단(승인/반려) 버튼은 항상 화면에 떠 있다.
3. **고정 캔버스** — 2560×1600 디자인 캔버스를 화면 크기에 맞춰 비율 그대로 축소한다.
4. **두 화면은 한 몸** — 레일·헤더·프로필·그림자·제목 크기가 동일해야 한다.

## 7. 접근성

- 헤더 그룹 링크: `aria-label="A Immune 관리자 대시보드"`, 로고 링크 `aria-label`
- 레일 버튼에 `title` 제공 (진행 대기 목록 / 민원 처리 내역 / 설정)
- 이미지 alt 제공, 로고 로딩 실패 시 텍스트로 대체
- 색만으로 위험도를 구분하지 않는다 — 뱃지에 **"위험도 + 단계 이름"** 글자가 항상 함께 표시됨
- 한계: 고정 캔버스를 축소하는 방식이라 작은 화면에서는 글자가 함께 작아짐

## 8. Do / Don't

| Do | Don't |
|---|---|
| 위험도는 빨강→주황→노랑→파랑 순서로 표시 | 우선순위 번호만 노출 ("우선순위 1") |
| 두 화면의 제목 크기·높이를 같게 (40px, y=220) | 화면마다 제목 크기가 달라지게 두기 |
| 두 화면의 그림자는 `shadow-nav` / `shadow-card` 하나로 | 화면마다 다른 그림자 값 |
| 지침 이름은 한 번만 표기 | "JOY-B07 JOY-B07" 중복 |
| 판단 버튼·반려 사유 박스는 플로팅 | 스크롤 끝까지 내려야 버튼이 보이게 하기 |
| 한글 제목은 `balance`로 줄 균형 | 단어 중간에서 끊기는 줄바꿈 |
| 헤더 요소는 가운데 정렬 | 뮤니·글자 높이 불일치 |
