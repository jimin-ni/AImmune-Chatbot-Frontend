# KT K New Deal AX ICT Academy Project

## A-IMMUNE (에이뮨) — 사내 AI 에이전트 통합 건의 소통 창구

> 전국 2,000여 개 대리점에서 사용하는 사내 AI 에이전트(JOY·SAM·흥부장 등)의
> 응답 지연·오답·근거자료 오류를 **현장 건의로 수집**하고, 지침서를 **버전 단위로 관리**하여
> *담당자가 근거를 보고 승인한 개정만* 에이전트에 반영되도록 통제하는 웹 시스템.

🔗 **데모/배포:** [배포 URL]  



## 🙋 담당 역할 — 프론트엔드 (사용자 접점 전 영역)

> **"사용자가 만지는 모든 화면"을 설계·구현, n8n 백엔드와의 데이터 연동, 테스트를 통한 디버깅, 기존 코드의 리펙토링**

- **사내 에이전트 예시 페이지** - 사내 에이전트와 직접 연동되는 사용자의 경험을 연결하기 위한 가상 에이전트와의 응답 홤녀 구축
- **건의 접수 폼** — 상담원이 넥서스에서 오류를 건의하는 입력 화면 구축
  - 필수값 공백 시 제출 차단, 접수 성공/실패 분기 안내, 이미지 첨부 처리
- **관리자 대시보드 (F03)** — 승인대기 개정안·기술 이슈를 구분 조회하는 운영 화면 구축
  - 지침 **변경 전 → 변경 후** 비교 표시, 위험도·우선순위·근거 건수 노출, 승인/반려 요청 연결
- **처리 내역 페이지 (history)** — 승인/반려 완료 건을 전체/승인/반려 필터로 조회하는 화면 신규 구축
- **(보조) n8n 연동** — 웹훅 **5종** 엔드포인트와 프론트 간 요청·응답 규격 정합 및 CORS/렌더링 처리

## 💡 문제 해결 & 회고

- **다양한 응답 필드명 흡수** — n8n 응답의 승인(`APPROVE`/승인)·반려(`REJECT`/반려) 값과 필드명이 혼재되어, 프론트에서 `normalizeItem` 정규화 로직으로 일관되게 렌더링하도록 처리.
- **변경 구간 비교 UI** — 전체 문구가 아닌 *실제 수정된 앞뒤 구간*만 추출해 변경 전/후를 비교 표시.
